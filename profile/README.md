## Starting an Autopsy Case

Prerequisites: A workstation with enough storage for evidence images, a verified copy of the tool, and a clear case folder for Autopsy case management.

1.  **Install the Application:** Complete an Autopsy download from a trusted project source, then install Autopsy software on the workstation that will be used for evidence review.
2.  **Create a Case:** Open Autopsy and define the case name, base directory, examiner information, and organization details so reporting begins with accurate context.
3.  **Add Evidence Sources:** Import disk images, local files, or other supported data sources, then configure ingest modules for Autopsy file recovery, hashing, keyword search, and artifact extraction.
4.  **Review and Report:** Use Autopsy forensic browser views, Autopsy timeline analysis, and extracted artifacts to document findings before generating a final report for stakeholders.
